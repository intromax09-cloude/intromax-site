# Аудит intromax.com.ua — 2026-11-04

Ветка `audit/2026-11-04`. Проверены: `index.html` (источник, UA), собранные `en/index.html` и `ru/index.html`, `privacy.html`, `sitemap.xml`, `robots.txt`, `_headers`, `functions/`, `i18n/`, `ai/`, история git (50 коммитов, все ветки).
В репозитории нет README. Сборка описана в шапке `i18n/build.js` (`node i18n/build.js`), база знаний агента — в `ai/about.md` и `ai/build-kb.js`.
Номера строк относятся к рабочему дереву после правок из этого PR (в `index.html` после строки 31 они сдвинуты на +1 к `main`).
Серьёзность ставил я. Размеры касания и контраст посчитаны по CSS, в браузере не измерялись.

## 5 самых важных

1. **JSON-LD показывает диапазоны цен, на странице — «від $X»** (high). Разметка Offer не совпадает с видимым текстом. Правка: решение Максима, цены в PR не трогал.
2. **Видимый текст всё ещё говорит о «діапазоні»**, хотя цены уже «від $X» (med). Затронуты блок цен и ответ в FAQ.
3. **Формы и API без защиты от спама** (med): `/api/lead`, `/api/review`, `/api/chat` пишут в Telegram владельца, а из защиты есть только honeypot, размер тела и лимиты по `sid`.
4. **Нет CSP и HSTS, нет кэша для `/img/*`** (med). Из-за 17 inline-скриптов CSP придётся вводить осторожно.
5. **Три языковые версии сайта не были в sitemap** (med, **исправлено в PR**), а у кнопок галереи Lavka не было имени для скринридера (med, **исправлено в PR**).

## Что проверено и в порядке

- **hreflang**: `uk` / `en` / `ru` / `x-default` во всех трёх файлах взаимные и совпадают; `canonical` и `og:url` у каждой языковой версии свои; `<html lang>` = `uk`/`en`/`ru`.
- **Мета**: `title`, `description`, `og:*`, `twitter:*` есть и переведены во всех трёх языках; `og-image.png` 1200×630 существует.
- **robots.txt**: `Allow: /`, указан sitemap.
- **Цены в трёх языках**: все 43 денежных токена (`$…`, `₴…`) одинаковы в UA/EN/RU.
- **i18n**: словари `en.json` и `ru.json` — по 1125 ключей, наборы совпадают, пустых переводов и застарелых ключей нет, кириллицы в EN-версии нет, украинских букв в RU-словаре нет; `en/` и `ru/` до моих правок были идентичны результату сборки.
- **Ссылки**: все внутренние `href="#…"` указывают на существующие id (две «ошибки» — строки-шаблоны JS `index.html:5357-5358`); `/privacy` и все `/img/*` существуют; дубликатов id нет (кроме шаблона JS); потерянных картинок нет; неиспользуемых файлов в `img/` нет.
- **Изображения**: у всех 12 `<img>` есть `alt`, `width`/`height`, `loading="lazy"`; вес 13 JPEG — 777 КБ суммарно, 30–87 КБ каждый. Конвертацию в WebP не делал: выигрыш небольшой, пришлось бы менять пути во всех языках.
- **Заголовки**: один `<h1>`, порядок h2 → h3 → h4 без пропусков.
- **Внешние ссылки**: у всех `target="_blank"` есть `noopener`.
- **Секреты**: токены берутся из `env` (`TG_TOKEN`, `TG_CHAT_ID`, `ANTHROPIC_API_KEY`). В дереве и истории (50 коммитов, все ветки) по шаблонам `sk-ant`, токен Telegram-бота, `AKIA`, `BEGIN … PRIVATE`, `ghp_`, `xox[bp]-` ничего не найдено. Проверка по шаблонам, полноценный сканер секретов не запускал.
- **Вес страницы**: `index.html` 367 КБ (98 КБ gzip), вся CSS и JS внутри файла.
